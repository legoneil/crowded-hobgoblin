# Duval Drive

A realistic first-person driving school simulator set in Jacksonville, Florida, built in Unity.
See [docs/DESIGN.md](docs/DESIGN.md) for the full game design.

## What's here (prototype)

- A drivable automatic student-driver car, seen from the driver's seat
- Working rear-view and side mirrors, turn signals that cancel themselves, headlights and brake lights
- Mouse head-look with mirror and shoulder checks that the game tracks
- A compressed **Riverside** neighborhood: Riverside Ave, Park St, Post St, Margaret St,
  Stockton St and King St, plus live oaks with Spanish moss, a riverfront along the St. Johns,
  a school zone, stop signs, a 4-way stop and a grocery-store parking lot
- A rules engine for Florida driving faults: speeding, school zones, rolling stops and running stop signs,
  missing or late signals, no mirror check, wrong side of the road, curbs and collisions
- An instructor, Ms. Delgado, who gives tips and reacts to how you drive

The scene is **generated by code** the first time you open the project, so you don't
have to build anything by hand.

## Setup on a Mac (first time)

1. **Install Unity Hub:** download it from <https://unity.com/download>, open it and sign in
   (a free Unity account and Personal license are fine).
2. **Install the editor:** in Unity Hub, go to **Installs → Install Editor** and choose the
   latest **Unity 6 LTS** version. The default options are fine.
3. **Get this project onto your Mac.** The easiest way is
   [GitHub Desktop](https://desktop.github.com):
   **File → Clone repository → `legoneil/crowded-hobgoblin`**. Then use the **Current branch**
   menu to switch to the branch this work is on.
4. **Open it in Unity:** in Unity Hub, go to **Projects → Add → Add project from disk** and pick the
   `crowded-hobgoblin` folder. If Hub asks which editor version to use, pick the Unity 6 one you installed.
5. **Wait for the first import.** It takes a few minutes. When it finishes, Unity builds the scene
   and shows a **"Let's drive"** popup.
6. Press **▶ Play** at the top of the window, **click inside the Game view**, and drive.

If anything goes wrong, open **Window → General → Console** and copy any red error text.

To regenerate the scene at any time, use the menu **Duval Drive → Rebuild Prototype Scene**.

## Controls

| Key | Action |
|---|---|
| W / ↑ | Accelerate |
| S / ↓ | Brake |
| A D / ← → | Steer |
| Space | Parking brake (it starts **on**) |
| F / R | Shift to Drive / Reverse (when stopped) |
| Q / E | Left / right turn signal |
| H | Hazards |
| L | Headlights |
| Mouse | Look around (look far left or right for a shoulder check) |
| Z / X / C | Glance at the left mirror / rear-view / right mirror |
| Backspace | Restart the lesson |
| Tab | Show or hide the controls |
| Esc | Free the mouse cursor |

## Project layout

```
Assets/_Project/
  Scripts/Core      DriverInput, Instructor, Surface
  Scripts/Vehicle   CarController, CarLights, EngineAudio
  Scripts/Player    DriverHeadLook (mouse look + mirror-check tracking)
  Scripts/Rules     RulesEngine, RoadSegment, StopZone, IntersectionZone
  Scripts/UI        DrivingHUD
  Editor            PrototypeSceneBuilder (generates the scene)
  Generated/        Materials and meshes made by the builder
  Scenes/           Riverside_Prototype.unity (made by the builder)
```
